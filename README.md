# 企业库存管理与智能补货自动化系统

一个基于 Python 的企业库存自动化项目：从 Excel 导入库存数据，自动完成数据校验、库存分析、补货建议，并生成规范的 Excel 分析报告，同时提供本地 Web 操作界面。

## 解决的业务问题

企业库存管理常依赖人工逐行核对 Excel，效率低、易遗漏。本项目把以下重复性工作自动化：

- 从 Excel 读取商品库存数据
- 校验数据完整性（名称、库存、编号重复、负数、非数字等）
- 判断库存状态（充足 / 临界 / 不足 / 异常）
- 识别库存不足商品并计算库存缺口
- 生成有依据的补货建议和补货优先级
- 输出格式规范、可直接查看的 Excel 分析报告

## 核心功能

| 模块 | 功能 |
|------|------|
| 数据导入 | 读取 .xlsx 库存文件，支持按表头自动识别列、跳过空白行 |
| 数据校验 | 名称/库存非空、数字校验、负数校验、编号重复检查、异常定位 |
| 库存分析 | 库存充足 / 临界 / 不足 三类状态判断 + 库存缺口计算 |
| 补货建议 | 补货量计算（有目标库存时）、补货优先级、补货原因 |
| 报告生成 | 4 个工作表：总览 / 明细 / 补货建议 / 异常记录，带样式 |
| Web 界面 | 本地 Streamlit 界面，上传文件、查看分析、下载报告 |
| 日志 | 标准库 logging，记录完整流程，便于排查问题 |

## 技术栈

- Python 3.13
- openpyxl：读写 Excel
- Streamlit：Web 界面
- pandas：数据展示与筛选
- pytest：自动化测试

## 系统架构

采用分层模块化结构，业务规则集中在 `config/settings.py`，各模块职责单一：

```
Excel 数据导入 → 数据校验 → 库存分析 → 补货建议 → 报告生成
```

详细说明见 [docs/architecture.md](docs/architecture.md)，业务流程图见 [docs/workflow.md](docs/workflow.md)。

## 安装步骤（Windows）

1. 安装 Python 3.10 及以上版本（本项目在 3.13 上验证）。
2. 在项目根目录打开命令行，安装依赖：

```bash
python -m pip install -r requirements.txt
```

## 启动步骤

方式一（推荐，双击即可）：双击项目根目录的 `run.bat`。

方式二（命令行）：

```bash
python -m streamlit run app.py
```

启动后浏览器会自动打开本地页面。在左侧「数据源」区域上传 Excel 文件，或点击「加载示例数据」体验完整流程。

## 测试方法

```bash
python -m pytest -v
```

测试覆盖：正常读取、库存状态判断、空名称、缺字段、字符串库存、负数库存、编号重复、目标库存缺失、补货量计算、报告生成、文件不存在、空文件等场景。

实测结果：**49 项测试全部通过**。

## 使用说明

1. 在左侧上传 `.xlsx` 库存文件（或点击「加载示例数据」）。
2. 在「首页」查看关键指标。
3. 在「库存分析」查看明细，可按状态筛选、按名称/编号搜索。
4. 在「补货建议」查看需要补货的商品及优先级。
5. 在「报告」下载自动生成的 Excel 分析报告。
6. 在「异常处理」查看数据异常记录及原因。

Excel 文件要求（表头按名称自动识别，列顺序可变化）：

- 必填列：`商品名称`、`当前库存`、`安全库存`
- 可选列：`商品编号`、`目标库存`、`商品单价`、`商品分类`、`商品单位`、`供应商`、`商品备注`

> 说明：只有存在「目标库存」时才会计算建议补货量；没有目标库存时，程序只提示库存缺口，不擅自编造采购数量。

## 当前版本的局限性

- 单机本地运行，未接入数据库，历史报告不持久化管理（仅按时间戳落盘）。
- 只支持 `.xlsx` 格式，不支持 `.xls`、CSV。
- 补货建议依赖「目标库存」字段；缺少时仅提示缺口，不自动估算采购量。
- Web 界面面向本地演示，未做多用户登录与权限管理。
- 示例数据为教学演示数据，不代表真实业务规模。
