# 系统运行截图

本目录存放系统实际运行时的界面截图，用于 README 展示，均使用 `data/sample/商品库存示例数据.xlsx` 运行得到。

| 顺序 | 文件名 | 展示内容 |
|------|--------|----------|
| 1 | `01_业务总览.png` | 首页：商品总数，以及库存充足、临界库存、库存不足、数据异常四项统计 |
| 2 | `02_库存分析.png` | 库存分析页：商品库存明细表，含库存状态、库存缺口，顶部为状态筛选与搜索框 |
| 3 | `03_补货建议.png` | 补货建议页：需要补货的商品、库存缺口、建议补货量、补货优先级与补货原因 |
| 4 | `04_Excel报告.png` | 生成的 Excel 报告：明细工作表，底部可见总览 / 明细 / 补货建议 / 异常记录 4 个工作表 |

四张截图按「业务总览 → 库存分析 → 补货建议 → Excel 报告」的业务流程顺序排列，在项目根目录 `README.md` 的「系统运行截图」章节中引用。
