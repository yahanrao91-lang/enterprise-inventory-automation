# 简历项目描述

> 说明：以下内容仅描述本项目真实实现并经过测试验证的功能，不虚构企业客户、业务规模、处理数据量、效率提升比例或生产环境部署经历。

## 项目名称

企业库存管理与智能补货自动化系统

## 项目背景

针对企业日常库存管理依赖人工逐行核对 Excel、效率低且易遗漏的问题，基于 Python 开发一套本地可运行的库存自动化处理系统，把数据导入、校验、分析、补货建议和报告生成整条流程自动化。

## 项目解决的问题

- 手工核对库存数据耗时、易错
- 库存状态（充足/临界/不足）需要人工逐行判断
- 库存不足的商品缺乏有依据的补货数量建议
- 数据异常（空值、负数、重复编号等）难以快速定位

## 使用的技术

- 语言：Python 3.13
- Excel 读写：openpyxl
- Web 界面：Streamlit
- 数据处理与展示：pandas
- 自动化测试：pytest
- 日志：标准库 logging

## 实际实现的功能

1. Excel 数据导入：按表头自动识别列，支持可选列缺失、跳过空白行。
2. 数据校验：名称/库存非空校验、数字校验、负数校验、商品编号重复检查，异常带 Excel 行号定位。
3. 库存分析：按业务规则将商品分为库存充足、临界库存、库存不足三类，并计算库存缺口。
4. 补货建议：有目标库存时计算建议补货量（目标库存 − 当前库存）；按可配置阈值划分补货优先级；无目标库存时不编造数量。
5. 报告生成：自动生成含 4 个工作表（总览/明细/补货建议/异常记录）的 Excel 报告，带表头样式、冻结窗格、自动筛选、状态标识和时间戳文件名。
6. Web 界面：本地 Streamlit 界面，支持上传文件、指标概览、状态筛选、关键字搜索、报告下载。
7. 日志系统：记录完整处理流程，便于排查问题。
8. 自动化测试：49 个测试用例全部通过，覆盖核心模块和端到端流程。

## 项目亮点

- 模块化分层设计，业务规则集中配置，易维护、易扩展。
- 异常数据不导致程序崩溃，而是记录并单独展示。
- 补货建议有明确计算依据，不虚构数据。
- 完整文档：架构说明、业务流程图、用户手册、演示脚本。
- 具备可现场演示的本地 Web 界面和可下载的 Excel 交付物。
