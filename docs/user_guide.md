# 用户使用手册

本手册面向非技术用户，介绍如何导入数据、查看结果、下载报告。

## 1. 启动系统

双击项目根目录的 `run.bat`，或让技术人员在命令行执行：

```bash
python -m streamlit run app.py
```

启动后浏览器会自动打开本地页面。

## 2. 导入库存数据

在页面左侧「数据源」区域：

- **上传文件**：点击「上传库存 Excel 文件」，选择你的 `.xlsx` 文件。
- **体验示例**：点击「加载示例数据」，系统会自动加载一份演示数据。

## 3. 数据要求

Excel 第一行是表头，必须包含以下三列（列名要完全一致）：

- `商品名称`
- `当前库存`
- `安全库存`

还可以有这些可选列：`商品编号`、`目标库存`、`商品单价`、`商品分类`、`商品单位`、`供应商`、`商品备注`。

> 想要系统给出「建议补货量」，请在数据里加上 `目标库存` 列并填写数值。

## 4. 查看结果

导入后，左侧导航有 6 个页面：

| 页面 | 作用 |
|------|------|
| 首页 | 看商品总数、充足/临界/不足/异常数量 |
| 数据导入 | 下载示例文件、预览导入的数据 |
| 库存分析 | 看每个商品的库存状态，可筛选、搜索 |
| 补货建议 | 看需要补货的商品、优先级和建议数量 |
| 报告 | 下载自动生成的 Excel 分析报告 |
| 异常处理 | 看哪些数据有问题、为什么 |

## 5. 下载报告

1. 点击左侧「报告」。
2. 点击「下载 Excel 分析报告」按钮，保存到本地。

报告包含 4 个工作表：

- **库存分析总览**：关键指标汇总
- **商品库存明细**：所有正常商品的库存情况
- **补货建议**：需要补货的商品
- **数据异常记录**：有问题的数据和原因

## 6. 常见问题

- **提示「缺少必填列」**：检查 Excel 表头是否包含「商品名称」「当前库存」「安全库存」。
- **某件商品进了「异常处理」**：一般是库存为空、不是数字、是负数，或编号重复，按提示修正后重新上传即可。
- **补货建议里「建议补货量」显示「待配置目标库存」**：说明这份数据没有「目标库存」列，系统不会乱猜采购量。
