# 现场演示脚本（3～5 分钟）

## 准备

- 已安装依赖：`python -m pip install -r requirements.txt`
- 双击 `run.bat` 启动系统，浏览器自动打开页面

## 演示流程

### 第 1 分钟：启动与加载数据

1. 双击 `run.bat`，浏览器打开本地界面。
2. 左侧点击「**加载示例数据**」。
3. 首页出现关键指标卡片：商品总数 8、库存充足 2、临界 1、库存不足 3、数据异常 2。

> 讲解点：这是一个完整的企业库存自动化流程，数据从 Excel 导入后自动完成分析。

### 第 2 分钟：库存分析与筛选

1. 点击左侧「**库存分析**」。
2. 看到每个商品的库存状态，不同状态有对应标识。
3. 用「按库存状态筛选」选择「库存不足」，表格只显示 3 件不足的商品。
4. 在搜索框输入「鼠标」，验证搜索功能。

> 讲解点：系统自动把商品分为充足/临界/不足三类，支持按状态和关键字快速定位。

### 第 3 分钟：补货建议

1. 点击「**补货建议**」。
2. 展示需要补货的商品，含「建议补货量」「补货优先级」「补货原因」。
3. 指出：显示器（库存 0）优先级是「急需补货」；有目标库存的商品给出了补货量。

> 讲解点：补货量 = 目标库存 − 当前库存，有依据才计算，不会乱编数字。

### 第 4 分钟：异常处理与报告下载

1. 点击「**异常处理**」，看到 2 条异常记录（当前库存为空、库存为负数），带 Excel 行号和原因。
2. 点击「**报告**」，点击「下载 Excel 分析报告」，打开下载的 Excel。
3. 展示报告里的 4 个工作表：总览 / 明细 / 补货建议 / 异常记录。

> 讲解点：数据有问题不会导致程序崩溃，而是被记录并单独展示；最终产出一份规范的分析报告。

### 收尾（可选）
